Projeto mobile feito em Flutter, Dart com banco não relacional Firebase. Ele consiste em um aplicativo contendo CRUD e autenticação de usuarios, onde o objetivo é consumir a APIs da Nasa e mostrar informações em telas especificas para o usuario. O aplicativo possui telas de Foto do dia, a API retorna uma imagem tirada por um telescopio hoje e exibimos em nosso app com titulo e explicação, na tela de favoritos do usuario é exibido uma listagem das imagens favoritas do usuario.
